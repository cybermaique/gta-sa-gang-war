# San Andreas: Gang War Offline

Mod single-player para GTA San Andreas, inspirado nos servidores SA-MP Gang War.

## Tecnologias

- TypeScript
- CLEO Redux
- CLEO 5
- Git

## Funcionalidades planejadas

- Sistema de gangues e ranking
- Conquista de territórios
- Gang Zones (GZs)
- Bases e economia
- Área 51 e disputa semanal
- IA estratégica das gangues
- Mundo persistente offline
- Bots avançados de combate
- Conversas e vozes com IA
